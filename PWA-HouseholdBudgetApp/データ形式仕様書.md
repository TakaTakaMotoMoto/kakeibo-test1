# 家計簿アプリ データ形式仕様書

## 概要
このドキュメントは、PWA家計簿アプリで使用されているデータ構造とパラメータの詳細を記載しています。

## 1. 取引（Transaction）データ

### 基本構造
```javascript
{
  id: string,                    // 一意識別子（自動生成）
  amount: number,                // 金額（正数：収入、負数：支出）
  categoryId: string,            // カテゴリID（必須）
  subcategoryId: string,         // サブカテゴリID（任意）
  fundSourceId: string,          // 資金元ID（必須）
  date: Date,                    // 取引日（必須）
  description: string,           // 説明・メモ（任意）
  
  // 共有機能関連
  createdBy: string,             // 作成者のユーザーID
  createdByUsername: string,     // 作成者のユーザー名
  isShared: boolean,             // 共有取引かどうか
  
  // タイムスタンプ
  createdAt: Date,               // 作成日時
  updatedAt: Date,               // 更新日時
  updatedBy: string              // 更新者のユーザーID（任意）
}
```

### パラメータ詳細
| パラメータ | 型 | 必須 | 説明 |
|-----------|---|------|------|
| id | string | ○ | 取引の一意識別子。自動生成される |
| amount | number | ○ | 取引金額。正数は収入、負数は支出を表す |
| categoryId | string | ○ | 関連するカテゴリのID |
| subcategoryId | string | - | 関連するサブカテゴリのID |
| fundSourceId | string | ○ | 使用した資金元のID |
| date | Date | ○ | 取引が発生した日付 |
| description | string | - | 取引の詳細説明やメモ |
| createdBy | string | - | 取引を作成したユーザーのID |
| createdByUsername | string | - | 取引を作成したユーザーの表示名 |
| isShared | boolean | - | 共有資金元での取引かどうか |
| createdAt | Date | ○ | レコード作成日時 |
| updatedAt | Date | ○ | レコード更新日時 |
| updatedBy | string | - | レコードを更新したユーザーのID |

## 4. 資金元（FundSource）データ

### 基本構造
```javascript
{
  id: string,                    // 一意識別子
  name: string,                  // 資金元名
  balance: number,               // 残高（取引により変動）
  type: string,                  // 資金元タイプ
  
  // グループ化機能
  groupId: string,               // 資金元グループID（任意）
  groupName: string,             // 資金元グループ名（任意）
  
  // クレジットカード紐づけ機能
  linkedBankAccountId: string,   // 紐づけ先銀行口座ID（creditタイプの場合）
  creditLimit: number,           // 利用限度額（creditタイプの場合）
  closingDay: number,            // 締め日（creditタイプの場合、1-31）
  paymentDay: number,            // 支払日（creditタイプの場合、1-31）
  
  // クレジットカード詳細情報
  cardNumber: string,            // カード番号（下4桁のみ保存、creditタイプの場合）
  cardBrand: string,             // カードブランド（VISA/MasterCard/JCB等）
  cardType: string,              // カード種別（一般/ゴールド/プラチナ等）
  expiryMonth: number,           // 有効期限月（1-12、creditタイプの場合）
  expiryYear: number,            // 有効期限年（YYYY、creditタイプの場合）
  

  
  // 銀行口座詳細情報
  bankName: string,              // 銀行名（bankタイプの場合）
  branchName: string,            // 支店名（bankタイプの場合）
  accountNumber: string,         // 口座番号（bankタイプの場合）
  accountType: string,           // 口座種別（普通/当座/定期など）
  
  // 共有機能関連
  ownerId: string,               // 所有者のユーザーID
  isShared: boolean,             // 共有されているかどうか
  sharedWith: Array,             // 共有ユーザーリスト
  permissions: Object,           // デフォルト権限設定
  
  // タイムスタンプ

}
```

## 資金元の紐づけ機能

### クレジットカードと銀行口座の紐づけ
クレジットカードは必ず引き落とし先の銀行口座と紐づけられます。

#### 紐づけのルール
1. **必須紐づけ**: `type: 'credit'`の資金元は`linkedBankAccountId`が必須
2. **循環参照禁止**: 銀行口座同士の循環参照は不可
3. **タイプ制限**: クレジットカードは銀行口座（`type: 'bank'`）とのみ紐づけ可能
4. **削除制限**: 紐づけられている銀行口座は、関連するクレジットカードが存在する限り削除不可

#### 残高計算への影響
- クレジットカード利用時は、紐づけ先銀行口座の残高には即座に影響しない
- 支払日（`paymentDay`）に一括で銀行口座から引き落とし処理を実行
- 利用限度額（`creditLimit`）を超える取引は警告表示

### グループ化機能

#### グループの用途例
- **家計**: 個人・家庭用の日常的な資金管理
- **会社用**: 事業・法人関連の資金管理
- **投資**: 投資・資産運用専用
- **その他**: 特定用途やプロジェクト専用

#### グループ機能の特徴
1. **視覚的分類**: 色とアイコンによる直感的な識別
2. **フィルタリング**: グループ別の取引表示・集計
3. **権限継承**: グループレベルでの共有設定
4. **レポート生成**: グループ別の収支レポート



## データ整合性とバリデーション

### 必須チェック項目
1. **参照整合性**: 取引のcategoryId、subcategoryId、fundSourceIdが存在するか
2. **紐づけ整合性**: クレジットカードのlinkedBankAccountIdが有効な銀行口座を参照するか
3. **グループ整合性**: 資金元のgroupIdが存在するグループを参照するか

4. **データ型**: 各フィールドが期待される型であるか
5. **権限階層**: 権限設定が論理的に正しいか
6. **日付妥当性**: 日付フィールドが有効な日付であるか
7. **メール形式**: メールアドレスが正しい形式であるか
8. **クレジット制限**: 利用限度額を超えていないか
9. **日付範囲**: 締め日・支払日が1-31の範囲内か
10. **カード有効期限**: クレジットカードの有効期限が未来の日付か
11. **カード番号形式**: カード番号が4桁の数字であるか

### 自動計算項目
- **資金元残高**: 取引の追加・更新・削除時に自動更新
- **共有ステータス**: 資金元の共有設定に基づいて取引の共有フラグを自動設定
- **クレジット残高**: 利用限度額からの残り利用可能額を自動計算
- **支払予定額**: 締め日ベースでの月次支払予定額を自動計算
- **カード有効期限アラート**: 有効期限が近づいたカードの自動通知

## 使用例

### 1. 銀行口座とクレジットカードの紐づけ例

```javascript
// メイン銀行口座
{
  id: "bank_main_001",
  name: "三菱UFJ銀行 普通預金",
  type: "bank",
  balance: 450000,
  groupId: "group1",
  groupName: "家計",
  bankName: "三菱UFJ銀行",
  branchName: "新宿支店",
  accountNumber: "1234567",
  accountType: "ordinary"
}

// 紐づけられたクレジットカード
{
  id: "credit_main_001",
  name: "三菱UFJカード",
  type: "credit",
  balance: -50000,  // 利用残高
  groupId: "group1",
  groupName: "家計",
  linkedBankAccountId: "bank_main_001",  // 上記銀行口座と紐づけ
  creditLimit: 500000,
  closingDay: 15,      // 毎月15日締め
  paymentDay: 10,      // 翌月10日支払い
  
  // クレジットカード詳細情報
```
