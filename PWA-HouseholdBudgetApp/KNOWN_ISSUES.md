# PWA家計簿アプリ - 既知の問題と制限事項

## 概要

このドキュメントは、PWA家計簿アプリケーションの既知の問題、制限事項、および回避策をまとめています。バグ修正後の現在の状況を反映しています。

## 現在の既知の問題

### 🔴 高優先度の問題

#### 1. 大量データでのパフォーマンス低下
**問題**: 取引データが1000件を超えるとアプリの動作が重くなる

**影響範囲**:
- 取引リストの表示が遅い
- グラフの描画に時間がかかる
- 検索・フィルター機能の応答が悪い

**回避策**:
- 定期的に古い取引データを削除
- 表示期間を制限（例：直近3ヶ月のみ）
- ページネーション機能の使用（将来実装予定）

**技術的詳細**:
```javascript
// パフォーマンス測定コード
console.time('transaction-render');
// 取引リスト描画処理
console.timeEnd('transaction-render');
```

#### 2. ローカルストレージの容量制限
**問題**: ブラウザのローカルストレージ容量（通常5-10MB）に達するとデータ保存ができない

**影響範囲**:
- 新しい取引の追加ができない
- 設定の保存ができない
- アプリが不安定になる

**回避策**:
- 定期的なデータクリーンアップ
- 不要な取引データの削除
- データエクスポート機能の使用

**確認方法**:
```javascript
// ストレージ使用量の確認
function getStorageUsage() {
    let total = 0;
    for (let key in localStorage) {
        if (localStorage.hasOwnProperty(key)) {
            total += localStorage[key].length;
        }
    }
    return `${(total / 1024).toFixed(2)} KB`;
}
console.log('Storage usage:', getStorageUsage());
```

### 🟡 中優先度の問題

#### 3. 共有機能のリアルタイム同期未対応
**問題**: 共有ユーザー間でのデータ同期がリアルタイムではない

**影響範囲**:
- 他のユーザーの変更が即座に反映されない
- データの競合が発生する可能性
- 共有状態の不整合

**回避策**:
- 手動でのページ更新
- 定期的なデータ同期（将来実装予定）
- 変更時の通知機能（将来実装予定）

#### 4. オフライン機能の制限
**問題**: 完全なオフライン対応が未実装

**影響範囲**:
- ネットワーク接続なしでは一部機能が制限される
- 共有機能がオフラインでは使用できない
- データ同期ができない

**回避策**:
- 基本的な家計簿機能はオフラインでも使用可能
- 重要なデータは事前にローカルに保存
- ネットワーク復旧後の自動同期（将来実装予定）

#### 5. モバイルブラウザでの表示問題
**問題**: 一部のモバイルブラウザで表示が崩れる場合がある

**影響範囲**:
- iOS Safari の古いバージョン
- Android の一部ブラウザ
- 画面サイズが極端に小さいデバイス

**回避策**:
- 最新版ブラウザの使用を推奨
- PWAとしてホーム画面にインストール
- 横画面での使用

### 🟢 低優先度の問題

#### 6. アクセシビリティの不完全対応
**問題**: スクリーンリーダーやキーボードナビゲーションの対応が不十分

**影響範囲**:
- 視覚障害者の利用が困難
- キーボードのみでの操作が制限される
- WCAG 2.1 AA基準を完全には満たしていない

**回避策**:
- 基本的な操作はマウス/タッチで実行
- 重要な情報はテキストでも提供
- 将来のアップデートで改善予定

#### 7. 多言語対応の未実装
**問題**: 日本語以外の言語に対応していない

**影響範囲**:
- 海外ユーザーの利用が困難
- 通貨表示が円のみ
- 日付形式が日本形式のみ

**回避策**:
- 現在は日本語環境での使用を前提
- 将来的に多言語対応を予定

## ブラウザ互換性の問題

### 対応ブラウザ
✅ **完全対応**:
- Chrome 80+
- Firefox 75+
- Safari 13+
- Edge 80+

⚠️ **部分対応**:
- Chrome 70-79（一部CSS機能が制限）
- Firefox 65-74（一部JavaScript機能が制限）
- Safari 12（PWA機能が制限）

❌ **非対応**:
- Internet Explorer 11以下
- Chrome 69以下
- 古いモバイルブラウザ

### 具体的な互換性問題

#### Internet Explorer
**問題**: ES6+の機能が使用できない
**影響**: アプリが全く動作しない
**対策**: モダンブラウザへの移行を推奨

#### 古いSafari（12以下）
**問題**: CSS Grid、CSS Variablesの対応が不完全
**影響**: レイアウトが崩れる
**対策**: Safari 13以上へのアップデート

## セキュリティ関連の制限

### 現在のセキュリティ対策
✅ **実装済み**:
- HTMLエスケープ処理
- 入力値検証
- XSS攻撃の基本的な防止

⚠️ **部分実装**:
- CSRF攻撃の防止（ローカルアプリのため影響は限定的）
- データ暗号化（ローカルストレージは平文）

❌ **未実装**:
- サーバーサイドでのデータ検証
- 高度な認証機能（OAuth等）
- 監査ログ機能

### セキュリティ上の注意事項

#### ローカルストレージの平文保存
**リスク**: 機密データが平文でブラウザに保存される
**対策**: 
- 共有PCでの使用は避ける
- ブラウザのプライベートモードの使用を検討
- 定期的なブラウザデータのクリア

#### 共有機能のセキュリティ
**リスク**: 共有データの不正アクセス
**対策**:
- 信頼できるユーザーとのみ共有
- 定期的な共有設定の見直し
- 不要な共有の削除

## パフォーマンス関連の制限

### 現在のパフォーマンス指標

#### 初期読み込み時間
- **目標**: 3秒以内
- **現状**: 2-4秒（データ量により変動）
- **制限要因**: 大量の取引データ

#### 操作応答時間
- **目標**: 1秒以内
- **現状**: 0.5-2秒（機能により変動）
- **制限要因**: DOM操作の最適化不足

#### メモリ使用量
- **目標**: 50MB以下
- **現状**: 30-80MB（使用時間により変動）
- **制限要因**: メモリリークの可能性

### パフォーマンス改善の推奨事項

#### ユーザー側での対策
1. **定期的なブラウザ再起動**: メモリリークの解消
2. **不要なタブの閉鎖**: メモリ使用量の削減
3. **古いデータの削除**: ストレージ容量の確保

#### 開発側での対策（将来実装予定）
1. **仮想スクロール**: 大量データの効率的表示
2. **遅延読み込み**: 必要な時のみデータを読み込み
3. **キャッシュ最適化**: 頻繁にアクセスするデータのキャッシュ

## データ関連の制限

### データ保存の制限

#### 取引データ
- **推奨上限**: 1000件
- **技術的上限**: ブラウザのストレージ容量による
- **制限理由**: パフォーマンス低下の防止

#### 添付ファイル
- **現状**: 未対応
- **制限理由**: ローカルストレージの容量制限
- **将来対応**: クラウドストレージとの連携予定

#### データエクスポート
- **対応形式**: JSON、CSV（将来実装予定）
- **制限**: 現在は手動でのローカルストレージコピーのみ

### データ整合性の問題

#### 同時編集
**問題**: 複数タブで同時編集時のデータ競合
**影響**: データの不整合や消失
**対策**: 
- 単一タブでの使用を推奨
- 定期的なデータバックアップ

#### データ復旧
**問題**: データ消失時の復旧機能が限定的
**影響**: 重要なデータの永続的な消失
**対策**:
- 定期的な手動バックアップ
- ブラウザの自動バックアップ機能の活用
