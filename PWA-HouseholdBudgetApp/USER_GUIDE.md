## はじめに

PWA家計簿アプリは、シンプルで使いやすいプログレッシブウェブアプリケーション（PWA）です。スマートフォン、タブレット、PCのどのデバイスでも使用でき、オフラインでも基本機能が利用できます。

### 主な特徴
- 📱 **マルチデバイス対応**: スマホ、タブレット、PCで使用可能
- 🔄 **オフライン対応**: インターネット接続なしでも基本機能が使用可能
- 👥 **共有機能**: 家族や友人とデータを共有
- 📊 **視覚的分析**: グラフとチャートで支出を分析
- 🎨 **直感的UI**: 使いやすいインターフェース

## インストールと初期設定

### ウェブブラウザでの使用

1. **ブラウザでアクセス**
   ```
   https://your-domain.com/PWA-HouseholdBudgetApp/
   ```

2. **動作確認**
   - ページが正常に読み込まれることを確認
   - 「家計簿PWA」のタイトルが表示されることを確認

### PWAとしてインストール

#### iPhone/iPad (Safari)
1. Safariでアプリを開く
2. 画面下部の共有ボタン（□↑）をタップ
3. 「ホーム画面に追加」を選択
4. アプリ名を確認して「追加」をタップ
5. ホーム画面にアイコンが追加される

#### Android (Chrome)
1. Chromeでアプリを開く
2. 右上のメニュー（⋮）をタップ
3. 「ホーム画面に追加」を選択
4. アプリ名を確認して「追加」をタップ
5. ホーム画面にアイコンが追加される

#### PC (Chrome/Edge)
1. ブラウザでアプリを開く
2. アドレスバーの右側にある「インストール」アイコンをクリック
3. 「インストール」ボタンをクリック
4. デスクトップにショートカットが作成される

### 初期設定

#### 1. 言語と地域設定
- アプリは日本語で表示されます
- 通貨は日本円（¥）で設定されています

#### 2. デフォルトデータの確認
アプリを初回起動すると、以下のデフォルトデータが自動作成されます：

**資金元**:

- 🏦 銀行口座
- 💳 クレジットカード

## 基本的な使い方

### 取引の追加

#### 1. 新しい取引を追加する
1. 画面右上の「+」ボタンをタップ
2. 取引フォームが表示される
3. 必要な情報を入力：
   - **金額**: 支出は負の値、収入は正の値で入力
   - **カテゴリ**: プルダウンから選択
   - **サブカテゴリ**: カテゴリ選択後に自動更新される選択肢から選択
   - **資金元**: 使用した資金源を選択
   - **日付**: デフォルトは今日、変更可能
   - **メモ**: 任意で詳細を記入
4. 「保存」ボタンをタップ

#### 2. 取引の編集
1. 取引リストから編集したい取引をタップ
2. 取引詳細画面で「編集」ボタンをタップ
3. 情報を修正して「保存」をタップ

#### 3. 取引の削除
1. 取引リストから削除したい取引をタップ
2. 取引詳細画面で「削除」ボタンをタップ
3. 確認ダイアログで「削除」を選択

### 資金元の管理

#### 1. 新しい資金元を追加
1. 「資金元」タブをタップ
2. 「+ 資金元を追加」ボタンをタップ
3. 資金元情報を入力：
   - **名前**: 資金元の名前（例：「メインバンク」）
   - **種類**: 現金、銀行口座、クレジットカードから選択
   - **初期残高**: 開始時の残高を入力
4. 「保存」ボタンをタップ

#### 2. 残高の調整
1. 資金元リストから調整したい資金元をタップ
2. 「残高調整」ボタンをタップ
3. 正しい残高を入力
4. 調整理由をメモに記入（推奨）
5. 「保存」をタップ

#### 3. 資金元の削除
- 取引で使用されていない資金元のみ削除可能
- 削除ボタンが表示されている資金元をタップして削除

### カテゴリとサブカテゴリの管理

#### 1. サブカテゴリの追加
1. 取引追加画面でカテゴリを選択
2. サブカテゴリ選択欄の「管理」ボタンをタップ
3. 「+ 新しいサブカテゴリ」をタップ
4. サブカテゴリ名を入力
5. 「保存」をタップ

#### 2. サブカテゴリの削除
- 取引で使用されていないサブカテゴリのみ削除可能
- サブカテゴリ管理画面で削除ボタンをタップ

### データの表示と分析

#### 1. カレンダービュー
1. 「取引」タブで「📅 カレンダー」ボタンをタップ
2. 月間カレンダーで取引を確認
3. 日付をタップして詳細を表示
4. 取引をタップして編集

#### 2. グラフ分析
1. 「📊 グラフ」タブをタップ
2. 表示タイプを選択：
   - **カテゴリ別**: 円グラフで支出の内訳を表示
   - **月次推移**: 線グラフで月ごとの推移を表示
3. 期間を選択してデータを絞り込み

#### 3. フィルター機能
1. 取引リストで「🔍 フィルター」ボタンをタップ
2. フィルター条件を設定：
   - **期間**: 開始日と終了日を指定
   - **カテゴリ**: 特定のカテゴリのみ表示
   - **資金元**: 特定の資金元のみ表示
   - **金額範囲**: 最小・最大金額を指定
3. 「適用」をタップしてフィルターを実行

## 高度な機能

### 認証とユーザー管理

#### 1. ユーザー登録
1. 画面右上の「ログイン」ボタンをタップ
2. 「新規登録」タブを選択
3. ユーザー情報を入力：
   - **ユーザー名**: 表示名
   - **メールアドレス**: ログイン用
   - **パスワード**: 8文字以上推奨
4. 「登録」ボタンをタップ

#### 2. ログイン
1. 「ログイン」ボタンをタップ
2. メールアドレスとパスワードを入力
3. 「ログイン」ボタンをタップ
4. ログイン成功後、ユーザー固有のデータに切り替わる

#### 3. ログアウト
1. 画面右上のユーザー名をタップ
2. 「ログアウト」ボタンをタップ
3. 共通データモードに戻る

### 共有機能

#### 1. 共有ユーザーの追加
1. 「⚙️ 設定」タブをタップ
2. 「共有管理」を選択
3. 「+ 共有ユーザーを追加」をタップ
4. 共有したいユーザーのメールアドレスを入力
5. 「追加」ボタンをタップ

#### 2. 資金元の共有設定
1. 共有管理画面で共有したい資金元を選択
2. 「共有開始」ボタンをタップ
3. 共有するユーザーを選択
4. 権限を設定：
   - **閲覧**: データを見ることができる
   - **編集**: データを変更できる
   - **削除**: データを削除できる
5. 「保存」をタップ

#### 3. 共有状態の確認
- 資金元リストで共有インジケーター（🔗）を確認
- 共有中の資金元には共有人数が表示される
- 取引リストで共有取引にはマークが表示される

#### 4. 共有の解除
1. 共有管理画面で解除したい共有を選択
2. 「共有停止」ボタンをタップ
3. 確認ダイアログで「停止」を選択

### データの管理

#### 1. データのバックアップ
```javascript
// ブラウザのコンソールで実行
const backup = {
    transactions: window.storage.getTransactions(),
    categories: window.storage.getCategories(),
    subcategories: window.storage.getSubcategories(),
    fundSources: window.storage.getFundSources(),
    sharingUsers: window.storage.getSharingUsers()
};
console.log('Backup data:', JSON.stringify(backup, null, 2));
// 出力されたJSONをファイルに保存
```

#### 2. データの復元
```javascript
// バックアップデータを復元（注意：既存データは上書きされます）
const backupData = { /* バックアップしたJSONデータ */ };
window.storage.setTransactions(backupData.transactions);
window.storage.setCategories(backupData.categories);
window.storage.setSubcategories(backupData.subcategories);
window.storage.setFundSources(backupData.fundSources);
window.storage.setSharingUsers(backupData.sharingUsers);
location.reload(); // ページを再読み込み
```

#### 3. データのクリア
```javascript
// 全データを削除（注意：復元不可能）
localStorage.clear();
location.reload();
```

## トラブルシューティング

### よくある問題と解決方法

#### 問題1: アプリが正常に動作しない
**症状**: ページが白い画面のまま、エラーが表示される

**解決方法**:
1. ブラウザを最新版に更新
2. ページを強制再読み込み（Ctrl+F5 または Cmd+Shift+R）
3. ブラウザのキャッシュをクリア
4. 別のブラウザで試す

#### 問題2: データが表示されない
**症状**: 取引や資金元が表示されない

**解決方法**:
1. ブラウザの開発者ツールを開く（F12）
2. Consoleタブでエラーを確認
3. 以下のコマンドを実行：
```javascript
window.storage.forceReinitialize();
location.reload();
```

#### 問題3: 追加ボタンが表示されない
**症状**: 資金元やカテゴリの追加ボタンが見えない

**解決方法**:
1. ページを再読み込み
2. 画面サイズを調整（ズームイン/アウト）
3. 以下のコマンドを実行：
```javascript
window.uiManager.renderFundSources();
```

#### 問題4: 共有機能が動作しない
**症状**: 共有ユーザーの追加や設定ができない

**解決方法**:
1. ログイン状態を確認
2. 最新版のファイルが読み込まれているか確認
3. ブラウザキャッシュをクリア

#### 問題5: パフォーマンスが悪い
**症状**: アプリの動作が重い、遅い

**解決方法**:
1. 古い取引データを削除
2. ブラウザを再起動
3. 他のタブを閉じる
4. デバイスのメモリを確認

### エラーメッセージの対処法

#### "updateAuthDependentUI is not defined"
**原因**: JavaScriptファイルの読み込み問題
**対処法**: ページを強制再読み込み、キャッシュをクリア

#### "Cannot read property 'getCurrentUser' of undefined"
**原因**: 認証システムの初期化問題
**対処法**: 
```javascript
// コンソールで実行
localStorage.removeItem('currentUser');
localStorage.removeItem('isLoggedIn');
location.reload();
```

#### "Storage initialization failed"
**原因**: ローカルストレージの容量不足
**対処法**: 不要なデータを削除、ブラウザデータをクリア

## よくある質問

### Q1: データはどこに保存されますか？
**A**: データはブラウザのローカルストレージに保存されます。サーバーには送信されないため、プライバシーが保護されます。

### Q2: 複数のデバイスでデータを同期できますか？
**A**: 現在は各デバイスで独立してデータが管理されます。将来的にクラウド同期機能を実装予定です。

### Q3: データが消失した場合、復元できますか？
**A**: 定期的にバックアップを取っていれば復元可能です。自動バックアップ機能は現在開発中です。

### Q4: 他の家計簿アプリからデータを移行できますか？
**A**: 現在は手動でのデータ入力のみ対応しています。将来的にインポート機能を実装予定です。

### Q5: オフラインでも使用できますか？
**A**: 基本的な家計簿機能（取引の追加、編集、削除、表示）はオフラインでも使用できます。共有機能は要インターネット接続です。

### Q6: セキュリティは大丈夫ですか？
**A**: データはローカルに保存され、基本的なセキュリティ対策を実装しています。共有PCでの使用は避け、定期的にブラウザデータをクリアすることを推奨します。

### Q7: スマートフォンで使いやすいですか？
**A**: レスポンシブデザインでスマートフォンに最適化されています。PWAとしてインストールすることで、ネイティブアプリのような体験が可能です。

### Q8: 無料で使用できますか？
**A**: はい、完全に無料で使用できます。広告もありません。

### Q9: アップデートはどのように行われますか？
**A**: ウェブアプリのため、ページを再読み込みすることで自動的に最新版が適用されます。

### Q10: サポートはありますか？
**A**: GitHub Issuesでバグ報告や機能要望を受け付けています。このユーザーガイドとトラブルシューティングガイドもご活用ください。
