### 初めて使用する場合
1. [README.md](README.md) - アプリの概要を理解
2. [USER_GUIDE.md](USER_GUIDE.md) - インストールと基本的な使い方を学習

### 問題が発生した場合
1. [TROUBLESHOOTING_GUIDE.md](TROUBLESHOOTING_GUIDE.md) - 具体的な解決手順を確認
2. [KNOWN_ISSUES.md](KNOWN_ISSUES.md) - 既知の問題かどうかを確認
3. [USER_GUIDE.md](USER_GUIDE.md) の FAQ セクション - よくある質問を確認

### 開発・保守を行う場合
1. [BUG_FIXES_DOCUMENTATION.md](BUG_FIXES_DOCUMENTATION.md) - 実装された修正内容を理解
2. [TEST_VALIDATION_SUMMARY.md](TEST_VALIDATION_SUMMARY.md) - テスト方法を確認
3. 各実装サマリー - 具体的な修正内容を詳細に確認

### 機能を詳しく知りたい場合

## 💡 ドキュメント活用のヒント

### 効率的な問題解決
1. **症状の特定**: 何が起こっているかを正確に把握
2. **適切なドキュメント選択**: 症状に応じたドキュメントを参照
3. **段階的な対処**: 簡単な解決方法から試す

### 学習の進め方
1. **概要から詳細へ**: README → USER_GUIDE → 技術ドキュメント
2. **実践的な学習**: 実際にアプリを使いながらドキュメントを参照
3. **定期的な見直し**: 新機能や改善点を定期的に確認

1. **修正前の確認**: 既知の問題や過去の修正内容を確認
2. **テストの実行**: 修正後は必ずテストシステムで検証
3. **ドキュメントの更新**: 新しい修正や機能追加時は文書も更新
