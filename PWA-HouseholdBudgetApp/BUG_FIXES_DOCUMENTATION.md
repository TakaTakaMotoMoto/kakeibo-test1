## 使用方法の更新

### 基本的な使い方

#### 1. 資金元の管理
1. 「資金元」タブをタップ
2. 「+ 資金元を追加」ボタンをタップ
3. 資金元情報を入力して保存
4. 削除は使用されていない資金元のみ可能

#### 2. カテゴリとサブカテゴリの管理
1. 取引追加時にカテゴリを選択
2. 選択したカテゴリに応じてサブカテゴリが自動更新
3. サブカテゴリ管理ボタンから新しいサブカテゴリを追加
4. 使用中のサブカテゴリは削除不可

#### 3. 共有機能の使用
1. 設定画面から「共有管理」を開く
2. メールアドレスを入力して共有ユーザーを追加
3. 資金元ごとに共有設定を変更
4. 共有インジケーター（🔗）で共有状態を確認

#### 4. 認証機能
1. ログインフォームでユーザー情報を入力
2. 認証成功後、自動的にユーザー固有データに切り替え
3. ログアウト時は共通データに戻る

### 新機能の使い方

#### データ検証機能
- ブラウザコンソールで `validatePWABugFixes.runAll()` を実行
- 個別機能の検証も可能

#### テスト機能
- `comprehensive-test-runner.html` でブラウザベーステスト
- 各種テストファイルで個別機能テスト

## トラブルシューティングガイド

### よくある問題と解決方法

#### 1. データが表示されない
**症状**: アプリを開いてもデータが表示されない

**原因と解決方法**:
- **ローカルストレージの問題**: ブラウザの開発者ツールでローカルストレージを確認し、必要に応じてクリア
- **初期化エラー**: ページを再読み込みして初期化を再実行
- **認証状態の問題**: ログアウト後、再ログインを試行

**確認手順**:
```javascript
// ブラウザコンソールで実行
console.log('Storage check:', window.storage);
console.log('Auth check:', window.authManager);
window.storage.forceReinitialize(); // 強制再初期化
```

#### 2. 資金元の追加ボタンが表示されない
**症状**: 資金元画面で追加ボタンが見えない

**原因と解決方法**:
- **CSS読み込み問題**: ページを強制再読み込み（Ctrl+F5）
- **JavaScript エラー**: 開発者ツールのConsoleでエラーを確認
- **初期化問題**: `window.uiManager.renderFundSources()` を実行

#### 3. カテゴリ選択時にサブカテゴリが更新されない
**症状**: カテゴリを選択してもサブカテゴリの選択肢が変わらない

**原因と解決方法**:
- **イベントリスナー問題**: ページを再読み込み
- **データ不整合**: デフォルトデータの再初期化を実行

**確認手順**:
```javascript
// サブカテゴリ更新の手動実行
window.uiManager.updateSubcategoryOptions('food'); // 食費カテゴリの場合
```

#### 4. 認証エラーが発生する
**症状**: ログイン時にJavaScriptエラーが発生

**原因と解決方法**:
- **メソッド未定義エラー**: 修正済みのファイルが正しく読み込まれているか確認
- **認証状態の不整合**: ローカルストレージの認証情報をクリア

**確認手順**:
```javascript
// 認証状態のリセット
localStorage.removeItem('currentUser');
localStorage.removeItem('isLoggedIn');
location.reload();
```

#### 5. 共有機能が動作しない
**症状**: 共有ユーザーの追加や設定ができない

**原因と解決方法**:
- **モックデータの残存**: 最新版のファイルが読み込まれているか確認
- **権限問題**: ログイン状態を確認

#### 6. パフォーマンスが悪い
**症状**: アプリの動作が重い、遅い

**原因と解決方法**:
- **大量データ**: 不要な取引データを削除
- **メモリリーク**: ページを再読み込み
- **ブラウザキャッシュ**: キャッシュをクリア

### エラーメッセージと対処法

#### "updateAuthDependentUI is not defined"
- **対処法**: 最新の `js/ui.js` ファイルが読み込まれているか確認
- **確認方法**: ブラウザの開発者ツールでファイルの更新日時を確認

#### "Cannot read property 'getCurrentUser' of undefined"
- **対処法**: AuthManagerの初期化を確認
- **確認方法**: `window.authManager` がコンソールで確認できるかチェック

#### "Storage initialization failed"
- **対処法**: ローカルストレージの容量を確認し、不要なデータを削除
- **確認方法**: 開発者ツールのApplicationタブでStorage使用量を確認

### デバッグ方法

#### 1. コンソールログの確認
```javascript
// デバッグモードの有効化
window.DEBUG = true;

// 各コンポーネントの状態確認

    storage: window.storage,
    authManager: window.authManager,
    uiManager: window.uiManager,
    dataManager: window.dataManager

```

#### 2. データ整合性の確認

```javascript

    if (!el.id) return;
```

## 既知の問題と制限事項

### 現在の制限事項

#### 1. オフライン機能
- **制限**: 完全なオフライン同期は未実装
- **影響**: ネットワーク接続が必要な場合がある
- **回避策**: 基本機能はオフラインでも動作

#### 2. 大量データの処理
- **制限**: 1000件以上の取引でパフォーマンス低下の可能性
- **影響**: 動作が重くなる場合がある
- **回避策**: 定期的な古いデータの削除

#### 3. ブラウザ互換性
- **制限**: Internet Explorer 11以下は非対応
- **影響**: 古いブラウザでは動作しない
- **回避策**: モダンブラウザの使用を推奨

#### 4. 共有機能の制限
- **制限**: リアルタイム同期は未実装
- **影響**: 共有データの更新に遅延がある
- **回避策**: 手動でのデータ更新
